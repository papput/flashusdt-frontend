# FLASH USDT PRO

Next.js + TypeScript frontend migrated from the original Vite React site in `flashusdtpro (3)`.

This is a visual/UI recreation. License activation, payment submit, and transfer submit keep the original non-success outcomes and do not perform real blockchain transactions.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Copy `.env.example` to `.env` and fill in wallet, WhatsApp, and Telegram values.

## Routes

- `/` Home
- `/pricing` Packages
- `/network` Network picker
- `/payment` Payment form
- `/coins` Coins
- `/form` Transfer form
- `/activation` License activation
- `/get-started` Guide + FAQ
- `/contact-us` Contact
- `/about` About
- `/terms` Terms
- `/privacy-policy` Privacy
- `/blog` Educational articles
